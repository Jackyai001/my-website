使用指南

1. 背调评级
每条展商都由系统按六个维度打分（触达通道 / 业务清晰 / 官网质量 / 名录信息 / 官方背书 / 数据可信）， 总分 100，≥70 为 A、≥45 为 B，点开详情能看到具体加分项，不靠感觉猜。

2. 可发邮件
只收录通过校验的邮箱：必须是这家公司自己的域名（或常见个人邮箱）、域名确实能收信（MX 记录正常）、且不是多家公司共用的假地址。不达标的一律不收。

3. 可发 WhatsApp
只收录展商官网自己标注的 WhatsApp 号码，并已校验号码合法性、排除被多家公司共用的号码。没有明确标注的一律不收（宁缺毋滥）。

4. 做什么的 / 主营产品
公司列表第二行就是简介摘要，详情弹窗里有完整简介和主营产品列表。

5. 导出
「导出结果」= 当前筛选；「导出选中」= 勾选的行；邮箱/WhatsApp 页各有专门的号码/邮箱清单导出。CSV 可直接用 Excel 打开。

6. 备份
所有标记存在本机浏览器，「备份/恢复」可导出 json 文件。

提示：数据来自展会官方目录与展商官网公开信息，仅供开发参考；开发客户请遵守目标平台规则，避免群发。
