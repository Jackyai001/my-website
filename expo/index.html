使用指南

1. 找客户
在「参展商名录」用左侧筛选：选国家、填城市或关键词，快速圈定目标市场。

2. 看资料
点公司名打开详情，含官网、展位号、邮编、州/CCI 等信息，可一键复制。

3. 存客户
点 ☆ 收藏，或勾选多家后「批量收藏」；在详情里写备注、设跟进状态。

4. 导出
「导出结果」= 当前筛选全部；「导出选中」= 勾选的行；「导出清单」= 收藏夹。CSV 可直接用 Excel 打开。

5. 备份
所有标记存在本机浏览器，「备份/恢复」可导出 json 文件，换电脑时导入即可。
