★如何购买与激活

本产品是付费授权软件，需要激活后才能使用。未激活时只能看到产品介绍首页，看不到任何客户数据 —— 名录是加密存放的，激活后才在本地解密。

激活方式是 买断制：一次付费，长期使用，没有月费年费、不会过期。

第一步：加客服开通账号

  1. 点下面的按钮添加企业微信客服（手机上会自动打开企业微信）。
  2. 发送「建材」两个字，并说明你的公司名和主营产品，方便客服给你报价。
  3. 确认付款后，客服会把你的专属激活码发给你。

点击添加客服，开通账号，可以试试

可以先试再说：加客服后说明你的业务和需求，客服会带你确认功能是否匹配（比如你做的是卫浴还是门窗、主要出口哪些国家），再决定要不要买。

第二步：激活

  1. 打开系统：https://jackyai001.github.io/my-website/
  2. 首页会自动弹出「产品激活」窗口（关掉也能通过顶部按钮重新打开）。
  3. 填三样：姓名 / 公司、手机号（必须和你报给客服的号码一致）、激活码。
  4. 点「立即激活」。成功后页面自动刷新，直接进入系统。
激活码与手机号绑定：激活码里的校验串由「授权号 + 手机号后四位」生成，所以手机号填错会提示"激活码与手机号不匹配"。也不能把激活码转发给别人 —— 别人用自己的手机号激活不了。

第三步：换设备 / 清过浏览器数据后怎么办

你的跟进记录、标签、备注都保存在本机浏览器里。如果清了浏览器数据、换了电脑，或者从线上版切到本地版，会出现"未激活"的状态：

  • 重新激活：用同一个手机号 + 同一个激活码重新填一次即可 —— 激活码是买断的，可以一直重复使用
  • 找回跟进记录：换设备前先在旧设备上「备份/恢复」→「导出备份（JSON）」，再到新设备导入
  • 忘了激活码：加客服，报你的姓名和手机号，客服可以从发码台账里帮你查回来

关于授权的常见问题

激活码能用几台设备？

同一个手机号可以在任意多台设备上激活，方便你换电脑、手机、平板。但激活码只跟一个手机号走，不能给别人用。

会过期吗？

不会。买断制，一次激活长期可用，没有月费或年费。

能给同事一起用吗？

需要给同事单独开通。因为跟进记录是各自保存在自己浏览器里的，一个账号无法让多人共享同一份跟进进度。如果需要团队协作，联系客服说明。

为什么我看不到客户数据？

未激活时名录是加密的，页面上不会出现任何客户信息，这是正常的。激活后即可看到全部 1132 条客户。

能修改或删掉内置的客户名录吗？

不能。内置名录是只读数据，产品里没有导入或删除名录的入口，避免误操作把客户数据弄丢。你可以在每位客户下补充参展届数、海外社媒和跟进记录。

1三分钟上手

  1. 打开系统：线上版 https://jackyai001.github.io/my-website/，或双击电脑上的 广交会建材客户背调筛选系统.html。页面顶部显示「客户总数 1132」就说明数据加载正常。
  2. 先填我方资料：进「开发信」页，右侧填公司名（英文）、业务员姓名、主营产品（英文）、WhatsApp、邮箱、网站、城市、出口年数。
    这一步很关键 —— 背调的「产品匹配」打分和后面所有话术，都靠这几个字段。
  3. 筛出今天要打的客户：进「客户名录」，左侧勾选条件（比如：等级选 A、国家选阿联酋+沙特、类目选卫浴洁具），右上角按「评分」排序。
  4. 看背调理由：点客户名打开详情，看「为什么是 A 级（评分依据）」，六项分数一目了然。觉得值得开发的，在「跟进记录」里标上状态和标签。
  5. 开始触达：进「批量触达」，选好范围，点「一键提取并生成差异化话术」，然后逐个「打开当前这条」→ 在 WhatsApp / 邮件里点发送 → 回来点「标记已发送 → 下一条」。
提示：第一次用建议先只做前 3 步，熟悉界面。触达是最后一步，想清楚再发。

参展届数怎么填

  • 单个填：打开客户详情 → 「参展届数」区 → 直接输入数字，或点 1 届 / 2 届 / 3 届 / 5 届 / 10 届 快捷按钮

说实话：原始名录里没有「第几次参加广交会」这个数据，任何声称能自动算出来的都是编的。这里给的是「人工核验 + 留档」的正规做法。

详情里「海外社媒账号」有三个输入框（领英 / 脸书 / Instagram），每个旁边有「搜」按钮 —— 用公司名去必应检索该平台的页面。查到后把链接或账号名粘进去，点「保存社媒记录」，之后列表会打上「领英·脸书」这类标签，导出也会带上。

联网核查是什么

点「客户名录」右上角的「联网核查」，程序会去查每个客户邮箱域名的 MX / SPF / DMARC / A 记录，判断：

  • 这个邮箱是不是真的能收信 —— 域名不存在的话，你写了一万字的开发信也是白写
  • 客户有没有官网 —— 有 A 记录说明有网站，公司真实性更高
  • 是不是正规运营的企业 —— 配了 SPF 通常说明有专职 IT 或至少懂点技术

用的是国内公共 DNS（阿里/腾讯/360），不需要翻墙。建议每次核查 200-300 条，分批跑；重复域名会自动复用已有结果。

5背调看板

一眼看清整份名录的质量和结构，用来决定「这一批客户先打哪个国家、哪个品类」。

  • 客户等级分布 —— A/B/C 各多少条
  • 客户类型分布 —— 贸易商、工程商、经销商、同行工厂各占多少
  • 邮箱情况 —— 企业邮箱 / 个人邮箱 / 无邮箱 / 格式无效
  • 重点国家 Top 20 —— 哪个国家的买家企业最多（印度 144、沙特 53、阿联酋 45……）
  • 数据质量与风险提示 —— 国家无法识别几条、疑似重复几条、邮箱必退信几条、无邮箱几条、号码区号不符几条、已核查多少条
怎么用：先看「数据质量」，把有问题的先剔掉；再看「重点国家」，挑一个你物流/认证最熟的市场，把那个国家的 A 级客户一次性干完，比撒胡椒面效率高得多。

6批量触达（WhatsApp / 邮件）

先把话说清楚：这套工具不能"一键群发"。
WhatsApp 只对通过认证的企业开放发消息接口，用脚本自动群发个人号必被封；浏览器的邮件又没有发信能力。任何号称能自动群发的工具，代价都是你的账号。
这里做的是半自动点对点：程序按客户的情况写好不同的内容 → 逐个打开并预填 → 你点发送 → 程序记录状态和节奏。慢一点，但账号是你的。

操作步骤

  1. 进「批量触达」，先选渠道：WhatsApp 触达 或 邮件触达。
  2. 右侧「目标范围」选客户：当前筛选结果 / 已勾选的客户 / 仅 A 级 / A+B 级 / 仅已核查通过的客户。
  3. 设好「今日发送上限」（默认 30）、「间隔下限/上限」（默认 25-70 秒随机）。
  4. 点「一键提取并生成差异化话术」→ 弹出风险确认 → 勾选「我已阅读并理解上述风险……」→ 点「确认并开始」。
  5. 程序自动完成：提取号码/邮箱（自动去重）→ 按采购类目 + 等级分组 → 每组用不同话术模板、组内措辞也随机变化 → 生成队列。
  6. 点「打开当前这条」→ WhatsApp / 邮件客户端弹出，内容已填好 → 你确认后发送。
  7. 回来点「标记已发送 → 下一条」，自动跳到下一位并开始随机间隔倒计时。
    不想发这个客户就点「跳过」。
  8. 想留档或换工具发，点「导出清单」下载 CSV。

队列界面怎么看

  • 四个统计：可触达客户 / 待处理 / 已发送 / 今日剩余额度
  • 当前客户：公司名、等级分数、国家、采购类目、本封用的话术名称
  • 号码：显示规范化后的国际号码，并注明原始号码（例如原始 017430512565 → +88017430512565）
  • 话术分组：右侧显示共分多少组、每组多少条、每组用了几种话术
  • 队列明细：每条带「待处理 / 已打开 / 已发送 / 已跳过」状态，点任意一条可切过去

话术是怎么"因人而异"的

  • 按类目：客户买瓷砖就提瓷砖，买卫浴就提卫浴
  • 按等级：A 级用完整卖点，C 级用最短问询
  • 按国家：话术里会注明"针对 {国家} 市场"
  • 组内轮换：WhatsApp 有 6 套开场（简洁问询 / 展会跟进 / 卖点切入 / 问题式开场 / 专业顾问式 / 短句低打扰），邮件有 4 套模板 + 4 种主题，同一组里也不会人人相同
  • 自动带入：联系人姓名、公司名、客户采购产品、你的公司名/产品/联系方式
话术模板可以在「开发信」页里改（邮件渠道用的就是那几套模板）。改完队列里的内容会自动重算。

关于发送节奏（这条最重要）

控制项建议值为什么
每日发送上限20–30 条新号或长期不活跃的号，超过 30 条/天风险陡增
随机间隔25–70 秒固定间隔（比如正好 30 秒一条）是典型的机器特征

分批推进一周 3-4 天，别连着一周天天发满给账号留正常的社交行为痕迹

7开发信生成

比批量触达更"重"的一封信，适合对 A 级客户做正式的首次开发或展会跟进。

怎么用

  1. 右侧先填「我方资料」8 项：公司名（英文）、业务员姓名、主营产品（英文）、WhatsApp/电话、邮箱、网站、工厂城市、出口年数。
  2. 上方选「目标客户范围」：当前筛选结果 / 已勾选 / 仅 A 级；用「切换查看第几条」翻看每封信。
  3. 选模板：内置 4 套 —— 初次开发信（标准）、广交会展会后跟进、WhatsApp 短消息、报价后催单。
  4. 直接在文本框里改模板（可用变量：{contact} 联系人、{company} 客户公司、{country} 国家、{products} 客户采购产品、{myCompany}、{myProducts}、{myName}、{myPhone}、{myEmail}、{city}、{years}），点「保存模板」。
  5. 点「复制当前」即可粘到邮箱/WhatsApp；点「导出全部（CSV）」得到每人一封的清单。
写开发信的三条经验：① 主题行别写 "We are a factory"，写客户关心的事（他的品类 + 市场）；② 正文别超过 150 字，AI 味越淡越好；③ 结尾一定要一个明确的小问题（"May I send our price list?"），让对方好回复。

8跟进管理

每个客户的进度都存在本机，不丢不乱。

状态怎么选

未联系 → 已发信 → 已回复 → 询价中 → 已报价 → 寄样中 → 已成交 → 暂搁置 / 无效客户

怎么记录

  • 点客户行 → 打开详情 → 底部「跟进记录」：选状态、点标签（重点客户 / 待验证 / 已加WhatsApp / 老客户 / 待报价 / 黑名单）、写备注、点「保存跟进」
  • 点「标记为今天已跟进」记录最后联系时间
  • 批量：勾选多个客户 → 工具条里「设置状态」「加标签」

跟进管理页

顶部是各状态的数量总览；下面是所有已建立跟进记录的客户，按最后跟进时间倒序，点「编辑」直接跳回该客户详情。点「导出跟进记录」可导出成 Excel 交给同事或做周报。

建议的工作节奏：每天开工先看「跟进管理」—— 哪些发了信没回（3 天后跟进一次的）、哪些报了价待确认、哪些该寄样了。有记录的开发才叫开发，没记录的就是碰运气。

按钮导出什么

点顶部「备份/恢复」：

10数据存在哪、怎么迁移

这套系统没有后台服务器，你录入的所有东西（跟进状态、标签、备注、参展届数、社媒、发送记录、话术模板）都保存在你自己电脑的浏览器里（localStorage）。好处是数据不上传、不怕泄露；代价是要理解下面几件事。

你会遇到的情况数据会怎样
同一台电脑、同一个浏览器、同一个网址数据一直在，正常使用
换浏览器（Chrome → Edge）数据看不到。属于两个独立的存储空间
线上版 ↔ 本地文件 ↔ 局域网版三份数据互不相通，因为网址不同
清理浏览器缓存 / 用无痕模式数据全部丢失，无痕模式关闭即清空
换电脑需要导出备份再导入
迁移口诀：旧的导出 JSON → 新的导入 JSON。表格数据（1132 条客户）是程序自带的，不用也不该迁移；要迁的只有你自己录进去的东西。

11常见问题

Q：点「写邮件」没反应 / 只打开了 Chrome 空白页

先确认两件事：
① 到「批量触达」右侧的「我的收发邮箱」里填上你自己的邮箱（例如 sales@你的公司.com），程序会自动识别该打开哪个网页邮箱；
② 如果提示「⚠ 没能自动识别」，说明你用的是公司自有域名，请在下面的「点「写邮件」时打开」下拉框里手动选一个（腾讯企业邮 / 阿里企业邮 / Outlook 365 等）。
另外，如果点完弹出的是空白页，检查浏览器是否拦截了弹窗 —— 地址栏右侧一般会有提示，点它选「始终允许」。

Q：我的邮箱不在下拉列表里，或者公司邮箱选哪个都不对

用「复制邮件内容」这个万能方案：在客户详情里点它，程序会把「收件人 + 主题 + 正文」整块复制到剪贴板，你随便打开一个邮箱点「写信」，粘贴进去就行 —— 收件人和主题也在里面，照着填即可。任何邮箱都能用，不挑服务商。

Q：WhatsApp 点开显示号码不对 / 打不开

看详情里的「原始号码」和规范化后的号码。程序会去掉前导 0 并补国家区号，但原始名录里有些单元格塞了好几个号码，会取最长的一段。如果发现补错了，直接复制原始号码手动加到通讯录再联系。

Q：「联网核查」点了没进度 / 显示查询失败

先确认网络正常（用的是国内阿里/腾讯 DNS，不需要翻墙）。如果整批都失败，多半是公司网络或安全软件拦截了 dns.alidns.com，换手机热点试试。另外每批不要超过 300 条，公共接口有速率限制。

Q：导入 Excel 提示无法解析 / 列名不识别

Excel 需要联网加载解析库。最稳的办法是在 Excel/WPS 里「另存为 CSV（UTF-8）」再导入。列名支持这些写法：采购商 / 公司 / Buyer、国家/地区 / Country、联系人 / Contact、手机 / WhatsApp、公司电话 / Tel、邮箱 / Email、采购产品 / Products、参展届数 / Fair。

Q：手机打不开局域网地址

检查三点：① 手机连的是不是和电脑同一个 Wi-Fi（不是流量）；② 有些公司/酒店 Wi-Fi 开了「客户端隔离」，会禁止手机访问电脑 —— 换成手机开热点、电脑连热点，再重新双击 bat；③ 以黑窗口里打印的那个地址为准，网段变了地址也会变。

Q：等级想调严一点 / 想改打分权重

现在的线是 A≥75、B≥60。觉得 A 太多就告诉我，我改成 A≥80。权重要调整（比如你觉得"企业邮箱"比"有座机"重要得多）也可以改。

Q：能不能直接群发？我客户太多了一个个发太慢

技术上不行，也不建议。真的量大就走"导出清单 + 邮件合并"：工具导出含「邮箱/主题/正文」的 CSV → Word → 邮件 → 选择收件人 → 使用现有列表 → 插入合并域 → 完成并合并 → 发送电子邮件（走 Outlook）。这样每个客户收到的是单独的、内容不同的信。

Q：名录里的客户数据会泄露吗

线上版是公开网页，所以那 1132 条客户数据（含手机号、邮箱）是任何人都能下载的，搜索引擎也会抓取 —— 这是你当初确认过的选择。你自己录进去的跟进记录、备注等只存在你本机浏览器里，不会上传、别人看不到。

Q：数据没保存上 / 刷新后少了

点「保存跟进」或切换状态后才会写入本机存储。如果用了无痕模式，关闭窗口就会清空。另外本地存储有容量上限（约 5MB），如果反复出现"本地存储已满"的提示，先导出备份，再删掉一些不再需要的记录。

12使用纪律（重要）

批量触达的后果由使用者自己承担。
WhatsApp 官方只允许通过认证的 Business API 发送商业消息；用个人号批量发营销内容，可能被限制发送、临时封禁甚至永久封号。邮件同理，可能让你公司的发件域名被列入黑名单，影响正常外贸往来。请遵守目标国家的反垃圾信息法规（GDPR、CAN-SPAM 等）。

六条实操纪律

  1. 先筛后发：只对「有企业邮箱 + 采购类目明确 + 非同行」的客户做首次触达，也就是优先 A 级。
  2. 控制节奏：每天 20-30 条，随机间隔 25 秒以上，一周别连着七天都发满。
  3. 内容要像人写的：别提"群发"、别用夸张词、别放大段图片、第一条别直接报价格。
  4. 优先 WhatsApp：建材客户在 WhatsApp 上回复率通常远高于邮件，而且没有那么强的垃圾判定。
  5. 记录一切：发完立刻标记状态。没记录的客户，等于没开发过。
  6. 长期主义：同一客户被拒绝两次之后就别死磕了，标「无效客户」，把精力留给下一个 A 级。
工具能帮你做的：把 1132 条乱名录变成有优先级、有理由、有内容、有记录的作战清单。
工具不能替你做的：判断一个客户值不值得长期投入、把询盘谈成订单。这两件事还得靠你。
