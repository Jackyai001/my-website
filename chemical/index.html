三种标注怎么看：
· ✓ 已核验：上面三道全过，可以放心发。
· ⚠ 待确认：存疑 —— 例如名录国家是香港、号码却是瑞典的；名录没写国家；疑似固话；号码拼接不全。这些不进名单，需要你自己看「原始号码」判断。
· ✕ 不可用：号码位数异常、无法解析，发不了。
以下市场不进本名单：美国、加拿大、墨西哥、柬埔寨（这些国家的手机与固话无法用号段区分，无法可靠挑出手机号）。注意：这只是「不进 WhatsApp 直发名单」——这些国家的客户在「客户名录」里完整保留，可用邮箱、领英等方式正常开发。
还要说清一点：已核验 ≠ 对方已注册 WhatsApp。名录来自展会登记信息，可能包含已停用号码、离职员工的号码、登记时填错的号码。是否注册只有 WhatsApp 自己知道，任何本地软件都无法离线确认。遇到提示未注册的，点「跳过」换下一位即可。

⚠ 发送前风险确认（必读）

批量触达存在账号与合规风险，请先确认你理解以下事实

  • WhatsApp：官方仅允许已认证的 Business API 发送商业消息。使用个人号批量发送营销内容，可能被判定为垃圾消息，导致限制发送、临时封禁甚至永久封号。
  • 邮件：未经许可的批量营销邮件可能被判定为垃圾邮件，导致发件域名或 IP 被列入黑名单，影响你公司的正常外贸邮件往来。
  • 本工具只做「逐个打开并预填内容」，不代替你点击发送，也不绕过任何平台限制；发送节奏、内容与数量由你决定。
  • 请遵守目标国家的反垃圾信息法规（如 GDPR、CAN-SPAM），并优先联系有明确合作意向的客户。
  • 降低风险的可行做法：控制在每日 20-30 条、随机间隔 25 秒以上、内容针对其采购类目定制、先发首条简短问询而非直接报价。

自动联网核查（邮箱域名真实性）
通过国内公共 DNS（阿里 / 腾讯 / 360，均支持浏览器直连）查询每条记录邮箱域名的 MX / SPF / DMARC / A 记录，判断该邮箱是否真实可收信、客户是否拥有官网，无需外网即可使用。
核查结果会写入名录并参与评分，可随时导出。全过程在本机浏览器完成，不上传客户数据。
提示：公共 DNS 接口有速率限制，建议每批不超过 300 条，分批核查即可。重复域名会自动复用已有结果。
